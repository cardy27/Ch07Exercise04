This C++ program prompts the user to enter a line of text, removes all vowels from the input string, and displays the resulting text.
It demonstrates the use of string manipulation functions, helper functions, and the substr method as required in Chapter 7, Exercise 4.

Overview

The user is asked to input a string.

The program calls a helper function isVowel(char) to check whether each character is a vowel (A, E, I, O, or U).

The removeVowels(const std::string&) function uses the substr method to build a new string that excludes all vowels.

Finally, the updated string is printed to the screen.
